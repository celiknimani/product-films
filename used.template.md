# Films made

Template for `private/used.md`, the log of every film made. Copy it there on first use: `mkdir -p private && cp used.template.md private/used.md`. The log stays out of git because it names clients.

Each new film's intro idea, motif and music must differ from every row. Other agents may be choosing at the same time, so claim your concept as soon as you choose it: re-read the file, change course if a row clashes, then append one row with "(in progress)" in the Date column. When you deliver, complete that same row. Never edit or remove other films' rows. Do not repeat the browser-to-phone morph used by several 2026-11-08 films.
