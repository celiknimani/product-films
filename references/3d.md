# 3D scenes

Use three.js when the request asks for 3D elements, a physical object (a roof, a house, a product) or fluid camera moves. The film's text stays in HTML on top of the canvas. Only graphics are 3D.

First made for a roofing ad (2026-10-31). If an earlier 3D film exists in `~/Movies/product-films/`, read its `initGL()` and `gl(t)` before writing a new scene.

## Setup

- Load `https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`. It renders headless in Playwright's Chromium with no extra flags.
- `new THREE.WebGLRenderer({canvas, antialias:true, alpha:true, preserveDrawingBuffer:true})`. `preserveDrawingBuffer` is required, or screenshots come back blank.
- `R.setClearColor(0,0)` and let the page background show through.
- Leave the output encoding at its default. Setting `outputEncoding = sRGBEncoding`, or converting vertex colours to linear, washed the brand colours out.
- Build the scene once in `initGL()` and only set positions, colours and the camera in `gl(t)`. Everything is set from `t`, as in the 2D scenes.

## Motion

- Camera: a keyframe list of `[time, [position], [target], fov]` read by a `track(t, keys)` helper with ease-in-out between keys. Hold a key for a beat before each cut so the cut lands on a still frame.
- 16:9 and Reel share one scene. Use `cam.setViewOffset` to shift the subject left in 16:9 (text on the right) or up in the Reel (text below), instead of moving the camera.
- Many repeated pieces (tiles, bricks, bars) go in one `InstancedMesh`. Setting each matrix from `t` is fast enough for 60fps capture.
- Morphs: give each instance a start pose and a target pose (for example every roof tile flying into the logo's shape) and blend with a staggered delay per instance.
- Random values come from a seeded hash such as `rnd(i)`, never `Math.random()`, or shards render different frames.

## Pitfalls

| Symptom | Cause | Fix |
| --- | --- | --- |
| Colours look grey and faded | sRGB output encoding | Remove it |
| A typed array throws a size error | Buffer built for a different count, such as 2600 rain drops into 2400 slots | Size the buffer from the same constant as the loop |
| A constant is undefined inside the camera keys | Keys were defined before the scene constants | Define keys after the constants they use |
| Scene renders once, then freezes in capture | Animation ran from `requestAnimationFrame` state | Call `gl(t)` from `scene(t)` and render inside it |
